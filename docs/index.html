便携模式

U盘一插，就是你的电脑

喵科大EC支持 --portable 便携启动，用户数据目录自动重定向到程序旁的 data/ 文件夹。无论你把它放在 U 盘、移动硬盘还是网盘同步目录， 所有书签、历史、登录状态都会跟着走。

  • ✓ 不写注册表，不留系统垃圾
  • ✓ 配置文件与程序同目录，拷走即迁移
  • ✓ Windows / Linux 双平台数据格式兼容
  • ✓ 云端登录后，跨设备配置自动合并
