FEATURES

为便携而生

01

真正免安装

下载即用，不写注册表，不残留系统目录。所有设置、历史、缓存跟随程序文件夹，拷走即完整环境。

02

Chromium 内核

与 Chrome 同源渲染引擎，网页兼容性、HTML5 支持、JavaScript 性能全部拉满，熟悉的浏览体验。

03

云端配置同步

注册登录后，书签、主页、主题、设置自动从云端下发。换台电脑登录，一切如旧。

04

版本自动检测

启动时自动向云端上报版本，实时对比最新版。有更新时提醒，不再错过新功能。

05

跨平台一致

Windows 与 Linux 双平台，相同的界面、相同的配置格式、相同的便携体验。

06

独立账号体系

PBKDF2 + SHA-256 加盐哈希，10万次迭代加密。独立云端，不与任何第三方账号耦合。
